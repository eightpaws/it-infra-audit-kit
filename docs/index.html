Как это получается

.\windows\Invoke-AdAudit.ps1 -OutFile out\ad-audit.jsonl
.\windows\Invoke-BackupAudit.ps1 -OutFile out\backup-audit.jsonl
./linux/audit-pve.sh out/pve-audit.jsonl
./linux/audit-backups.sh out/backup-audit.jsonl
python3 tools/render.py out/*.jsonl -o out/report.md

Каждая находка - одна строка JSONL: {"check","value","severity","note"}. Поэтому отчёт можно собрать из любого набора скриптов, в том числе добавить свой (Veeam, PBS, чужой мониторинг) и не переписывать рендер.

Почему проверки именно такие

Список собран не из статей, а из рабочих грабель, каждая описана в репозитории: MachineAccountQuota отдаёт коллекцию вместо числа; Get-DnsServerZone без -ComputerName молча возвращает пустоту; «задание завершено успешно» не значит «восстановится»; режим suspend в vzdump останавливает виртуальную машину. Пустое значение в отчёте помечается как находка, а не как норма.

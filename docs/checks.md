# Проверки и что они означают

Список проверок с уровнями риска. Названия совпадают с полем `check` в JSONL, поэтому по отчёту всегда видно, какой скрипт и какая проверка дали находку.

## Домен и контроллеры

| Проверка | Уровень по умолчанию | Что значит |
|---|---|---|
| `domain.context` | high | домен недоступен, дальше проверять нечего |
| `domain.forestMode` | info | режим леса: смена требует бэкапа и окна |
| `domain.pdcEmulator` | info | где живёт PDC, проверять `netdom query fsmo` |
| `dc.count`, `dc.globalCatalog` | info | сколько контроллеров и глобальных каталогов |
| `fsmo.owners` | medium | роли не прочитаны: `netdom` отсутствует или нет прав |
| `replication.errors` | critical | есть ошибки репликации: разбирать по контроллерам |
| `groups.Domain Admins` | medium при составе больше 7 | раздутая группа администраторов домена |
| `groups.Protected Users` | high при нуле | ключевые админы не защищены от кражи тикетов |
| `accounts.adminCount` | medium | остаточные права после вывода из групп |
| `accounts.passwordNeverExpires` | medium | делить на сервисные и забытые |
| `accounts.inactiveUsers` | medium | решение владельца, не массовое удаление |
| `computers.inactive` | low | сверка с парком |
| `computers.lapsCoverage` | medium при покрытии ниже 90% | остаток машин с общим локальным паролем |
| `krbtgt.passwordAgeDays` | high при возрасте больше года | ротация по регламенту |
| `gpo.partiallyDisabled` | medium | половина политики выключена, эффект не тот, что ждут |
| `domain.machineAccountQuota` | medium при значении больше 0 | любая учётка может завести компьютерный объект |
| `dns.zones` | low при ошибке чтения | запрос без `-ComputerName` уходит не туда |

## Резервное копирование Windows

| Проверка | Уровень | Что значит |
|---|---|---|
| `wbadmin.versions` | high | версий нет или нет прав: копий нет либо неизвестно |
| `wbadmin.lastBackupAgeHours` | high при возрасте больше порога | старая копия не защищает от шифровальщика |
| `wbadmin.versionsCount` | info | сколько версий найдено |
| `gpo.backup` | high при пустом каталоге | `Backup-GPO` не запускался |
| `gpo.backupAgeDays` | medium при возрасте больше 30 дней | бэкап политик устарел |
| `vss.failedWriters` | high при наличии | теневое копирование сломано, копия будет неполной |
| `dsrm.passwordSaved` | medium | пароль восстановления не подтверждён |

## Гипервизор Proxmox VE

| Проверка | Уровень | Что значит |
|---|---|---|
| `cluster.quorum` | critical при потере | конфигурацию менять нельзя |
| `backup.jobs` | critical при отсутствии | у виртуалок нет регулярного бэкапа |
| `backup.jobsDisabled` | high | задание есть, но выключено |
| `backup.mode` | high при `suspend` | бэкап останавливает виртуалку |
| `backup.lastRunDays` | medium при возрасте больше 3 дней | прогонов давно не было |
| `backup.lastRun` | high | последний лог без строки `Finished Backup` |
| `storage.<имя>` | high при заполнении от 85% | бэкап перестанет помещаться |
| `replication.jobs` | info | репликация настроена, статус проверять отдельно |
| `config.lastChangeHours` | info | когда менялась конфигурация кластера |

## Резервное копирование Linux

| Проверка | Уровень | Что значит |
|---|---|---|
| `schedule.timers` | medium при отсутствии | расписание не найдено среди systemd-таймеров |
| `path.local`, `path.srv`, `path.mnt` | high при возрасте больше 7 дней | копии в этом каталоге устарели |
| `db.postgres` | medium | дампы баз не найдены |
| `restore.lastDrillDays` | high при отсутствии журнала | восстановление ни разу не проверялось |

## Как читать уровни

- **critical** — прямо сейчас есть риск остановки или потери данных, чинить первым;
- **high** — защита формально есть, но при инциденте не сработает;
- **medium** — расхождение с практикой, которое накапливается в проблему;
- **low** — данные не получены, надо разобраться, почему;
- **info** — контекст для отчёта, не требует действий.

Уровни зашиты в скрипты и легко меняются: это одна строка в вызове `Add-Finding`.
